#### **1. Arrays**

**Characteristics**:

- Fixed-size, contiguous memory
- Homogeneous elements (same data type)
- Zero-based indexing

**Dimensions**:

Python

```
# 1D Array
students = ["Alice", "Bob", "Charlie"]

# 2D Array (Matrix)
grid = [[1, 2, 3], 
        [4, 5, 6]]

# 3D Array
cube = [[[1,2], [3,4]], 
        [[5,6], [7,8]]]
```

**Operations**:

- Access: `grid[1][2]` → 6
- Update: `students[0] = "Alicia"`
- Search: O(n) time complexity

#### **2. Stacks (LIFO)**

**Implementation**:

Python

```
stack = []
stack.append("A")  # Push
item = stack.pop() # Pop
```

**Pointer-Based**:

C

```
int stack[MAX];
int top = -1;

void push(int value) {
    stack[++top] = value;
}

int pop() {
    return stack[top--];
}
```

**Use Cases**:

- Function call management
- Undo/redo operations

#### **3. Queues (FIFO)**

**Implementation**:

Python

```
from collections import deque
queue = deque()
queue.append("A")  # Enqueue
item = queue.popleft() # Dequeue
```

**Circular Queue**:

C

```
int queue[MAX];
int front = 0, rear = -1;

void enqueue(int value) {
    rear = (rear + 1) % MAX;
    queue[rear] = value;
}
```

**Use Cases**:

- Printer task scheduling
- Breadth-first search

#### **4. Linked Lists**

**Types**:

- Singly-linked
- Doubly-linked
- Circular

**Node Structure**:

Python

```
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None
```

**Operations**:

- Insertion: O(1) at head
- Deletion: O(n) worst case
- Search: O(n)

#### **5. Trees**

**Binary Search Tree**:

Python

```
class TreeNode:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None
```

**Traversal**:

- In-order: Left → Root → Right (sorted output)
- Pre-order: Root → Left → Right (copying trees)
- Post-order: Left → Right → Root (deletion)

**Balancing**:

- AVL trees maintain |left height - right height| ≤ 1

#### **6. Hash Tables**

**Components**:

- Hash function (e.g., division method)
- Collision resolution:
    - Chaining (linked lists)
    - Open addressing

**Example**:

Python

```
hash_table = [None] * 10

def hash_func(key):
    return key % 10

def insert(key, value):
    index = hash_func(key)
    if not hash_table[index]:
        hash_table[index] = []
    hash_table[index].append((key, value))
```

### **Key Comparisons**

|Structure|Access|Search|Insert/Delete|Use Case|
|---|---|---|---|---|
|Array|O(1)|O(n)|O(n)|Fixed-size collections|
|Stack|O(1)*|O(n)|O(1)|LIFO operations|
|Queue|O(1)*|O(n)|O(1)|FIFO operations|
|Linked List|O(n)|O(n)|O(1)|Dynamic size|
|BST|O(log n)|O(log n)|O(log n)|Ordered data|
|Hash Table|O(1)|O(1)|O(1)|Fast lookups|

*Only top/front element access

### **Memory Representations**

**Array-Based Binary Tree**:

- Parent at index `i`
- Left child: `2i + 1`
- Right child: `2i + 2`

**Linked List Node**:

text

```
+-----+-----+
| Data| Next|
+-----+-----+
```

### **Implementation Tips**

1. **Stack Overflow**: Always check bounds before push/pop
2. **Queue Underflow**: Verify `front <= rear` before dequeue
3. **Tree Balancing**: Rotate nodes during insertion if needed
4. **Hash Collisions**: Use prime-number table sizes

### **Real-World Applications**

- **Arrays**: Image processing (pixel matrices)
- **Stacks**: Browser history
- **Queues**: Ticket booking systems
- **Trees**: Filesystem organization
- **Hash Tables**: Database indexing
