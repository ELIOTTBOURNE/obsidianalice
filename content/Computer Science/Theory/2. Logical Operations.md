### **2. Applying Logical Operations in Programming**

#### **Clearing Registers**

- Use **AND** with `0` or **XOR** with itself to reset a register to `0`:
    

Python

- ```
    register = register & 0b00000000  # AND method  
    register = register ^ register    # XOR method  
    ```
    

#### **Masking**

- Extract specific bits using **AND** with a bitmask:
    

Python

- ```
    # Check if 3rd bit is set (assuming 8-bit register):  
    masked_value = data & 0b00100000  # Yields 0b00100000 if bit is 1  
    ```
    

#### **Encryption (XOR Cipher)**

- XOR is reversible, making it useful for simple encryption:
    

Python

- ```
    ciphertext = plaintext ^ key  # Encryption  
    decrypted = ciphertext ^ key  # Decryption  
    ```

### **3. Simplifying Boolean Expressions**

#### **Boolean Identities**

1. **Commutative Laws**:
    - `P ∧ Q ≡ Q ∧ P`
    - `P ∨ Q ≡ Q ∨ P`
2. **Associative Laws**:
    - `(P ∧ Q) ∧ R ≡ P ∧ (Q ∧ R)`
    - `(P ∨ Q) ∨ R ≡ P ∨ (Q ∨ R)`
3. **Distributive Laws**:
    - `P ∧ (Q ∨ R) ≡ (P ∧ Q) ∨ (P ∧ R)`
    - `P ∨ (Q ∧ R) ≡ (P ∨ Q) ∧ (P ∨ R)`

#### **De Morgan’s Laws**

- **Negation of AND/OR**:
    - `¬(P ∧ Q) ≡ ¬P ∨ ¬Q`
    - `¬(P ∨ Q) ≡ ¬P ∧ ¬Q`

**Example Simplification**:  
Original: `¬(A ∧ B) ∨ (¬A ∧ B)`  
Apply De Morgan’s: `(¬A ∨ ¬B) ∨ (¬A ∧ B)`  
Distribute: `¬A ∨ (¬B ∨ (¬A ∧ B))`

|**Operation**|**Use Case**|**Example**|
|---|---|---|

|**OR**|Setting bits|`flags = flags|
|**XOR**|Encryption/Toggling bits|`data ^ 0b10101010` (flip alternating bits)|

### **Worked Example: Simplifying with De Morgan’s**

**Expression**: `¬(P ∨ (¬Q ∧ R))`

1. Apply De Morgan’s:  
    `¬P ∧ ¬(¬Q ∧ R)`
2. Apply De Morgan’s again:  
    `¬P ∧ (Q ∨ ¬R)`

**Result**: Simplified to `¬P ∧ (Q ∨ ¬R)`.
