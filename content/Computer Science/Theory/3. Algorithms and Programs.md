### **Algorithms**

#### **What is an Algorithm?**

An **algorithm** is a step-by-step procedure to solve a problem or perform a computation.

**Example**:

- **Problem**: Sort a list of names alphabetically.
- **Input**: `["Zoe", "Alice", "Bob"]`
- **Output**: `["Alice", "Bob", "Zoe"]`

#### **Methods of Defining Algorithms**

1. **Pseudocode**
    
    - A high-level description using natural language and programming-like syntax.
    - **Example (Linear Search)**:
        
        `FUNCTION linear_search(list, target)`  
            `FOR each item IN list`  
                `IF item == target THEN`  
                    `RETURN item’s position`  
                `END IF`  
            `NEXT item`  
            `RETURN -1  # Not found`  
        `END FUNCTION`  
        
     **Flowcharts**
    
    - Visual representation using standard symbols:
        - **Oval**: Start/End.
        - **Rectangle**: Process (e.g., calculations).
        - **Diamond**: Decision (e.g., `IF` statements).
        - **Parallelogram**: Input/Output.

### **Recursion**

#### **What is Recursion?**

A function that calls itself until a **base case** is reached.

**Example (Factorial)**:

Python

```
def factorial(n):  
    if n == 1:  
        return 1  
    else:  
        return n * factorial(n - 1)  
```

- **Efficiency**: O(n) time, O(n) space (due to call stack).
- **Elegance**: Simplifies problems like tree traversals or divide-and-conquer (e.g., quicksort).

### **Sorting Algorithms**

#### **Why Different Algorithms?**

- **Recursive** (e.g., quicksort, merge sort): Efficient for large datasets.
- **Non-recursive** (e.g., bubble sort): Simpler but less efficient.

#### **Key Characteristics**

|**Algorithm**|**Time Complexity**|**Space Complexity**|
|---|---|---|
|Bubble Sort|O(n²)|O(1)|
|Quicksort|O(n log n) avg.|O(log n)|

**Efficiency Factors**:

- **Storage space**: Merge sort uses O(n) extra space.
- **Comparisons/exchanges**: Bubble sort performs excessive swaps.
- **Passes**: Insertion sort requires fewer passes if partially sorted.

**Big O Notation**:

- **Quicksort**: O(n²) worst-case (if pivot is poorly chosen).

### **Searching Algorithms**

#### **Types**

1. **Linear Search**
    - O(n) time; checks every element.
2. **Binary Search**
    - O(log n) time; requires sorted data.

**Shortest-Path (Dijkstra’s Algorithm)**:

- Finds the shortest path in a weighted graph.
- **Steps**:
    1. Calculate distances from the start node.
    2. Update distances recursively if a shorter path is found.

### **Compression**

#### **What is Data Compression?**

Reducing file size to save storage/bandwidth.

#### **Lossy vs Lossless**

|**Type**|**Pros**|**Cons**|
|---|---|---|
|Lossy|Smaller files (e.g., JPEG)|Irreversible data loss|
|Lossless|No data loss (e.g., ZIP)|Larger files|

**Algorithms**:

1. **Run-Length Encoding (RLE)**:
    - Repeats replaced with count (e.g., `AAAABBB` → `4A3B`).
2. **Dictionary Encoding**:
    - Repeats replaced with dictionary indices.

**Comparison Metrics**:

- **Compression ratio**: `(compressed size / original size)`.
- **Saving percentage**: `(1 − ratio) × 100%`.
